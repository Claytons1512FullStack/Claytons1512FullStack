# 🚀 Projetos em destaque

## 🔹 TAGOX Flow

**Plataforma de gestão e atendimento profissional do ecossistema TAGOX.**

Projeto desenvolvido com foco em uma arquitetura **SaaS multi-tenant**, onde cada empresa possui seus próprios dados e usuários isolados.

### Tecnologias

```text
Java
Spring Boot
Spring Data JPA
Hibernate
PostgreSQL
Flyway
Maven
JUnit
REST API
```

### Arquitetura

O projeto está sendo estruturado com preocupação especial em:

* 🏢 Isolamento por empresa (Tenant)
* 👤 Gestão de usuários
* 🔐 Controle de acesso baseado em papéis (RBAC)
* 🧩 Arquitetura modular
* 🗄️ Persistência relacional
* 🔄 Migrações versionadas com Flyway
* 🧪 Testes automatizados
* ⚠️ Tratamento centralizado de exceções
* 📦 DTOs e validações
* 🔒 Regras de segurança e isolamento de dados

🔗 **Repositório:**
https://github.com/Claytons1512FullStack/tagox-flow
